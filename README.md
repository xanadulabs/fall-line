# Fall Line

The snow left. The hill stayed.

A downhill dodge on a dry mountain. Three rides: an offroad skateboard, a mountain bike, and a motor bike. Stay on the dirt. Bigfoot shows up if you go too far.

## Status

Design in `MODE_BIBLE.md` (v0.1). The first slice plays: pick a ride, go down, crash or get caught. Run it with `godot --path game`.
